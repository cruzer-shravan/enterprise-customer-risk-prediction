# 🚀 Enterprise Customer Risk Prediction

## 📌 Problem Statement

Customer churn is a major revenue risk. This project predicts which customers are likely to leave, enabling proactive retention strategies.

---

## 🧠 Solution Overview

* Built an end-to-end ML pipeline for churn prediction
* Applied feature engineering on telecom dataset
* Trained multiple models (Logistic Regression, Random Forest, XGBoost)
* Selected best model based on ROC-AUC

---

## 🏗️ Architecture

Data → Processing → Feature Engineering → Model Training → API → Dashboard

---

## ⚙️ Tech Stack

* Python, Pandas, NumPy
* Scikit-learn, XGBoost
* Streamlit / FastAPI
* Docker (optional)

---

## 📊 Results

* ROC-AUC: **0.91**
* Accuracy: **85%**
* Precision-Recall optimized for churn class
